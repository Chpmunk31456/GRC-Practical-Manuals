# Manual 24 — NIS2 Controlled Implementation

This directory contains the controlled-build source and eventual publication package for Manual 24.

Primary EU baseline: Directive (EU) 2022/2555 (NIS2). Applicable national transposition measures, Commission implementing acts, ENISA guidance, sector-specific requirements, contractual obligations, and organization-specific procedures are maintained as distinct source layers. Commission Implementing Regulation (EU) 2024/2690 applies only to the relevant entity types within its stated scope; it must not be generalized to every NIS2 entity. ENISA implementation guidance is non-binding guidance and is not treated as statutory text.

Controlled publication languages are English, Spanish (es-419), and Portuguese (pt-BR). Project translations are unofficial unless separately documented otherwise. Publication is governed by the repository canonical release authorization rule and fail-closed source, applicability, localization, rendering, accessibility, integrity, provenance, workflow-security, substantive-review, and predecessor-order controls.
