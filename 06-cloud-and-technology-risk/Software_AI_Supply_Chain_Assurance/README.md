# Manual 29 — Software / AI Supply Chain Assurance

Controlled implementation manual for software, model, component, build, dependency, provenance, SBOM/VEX, and third-party supply-chain assurance.

## Controlled baselines

- NIST SP 800-218 SSDF Version 1.1 — final stable baseline.
- NIST SP 800-218A — final AI community profile used with SSDF 1.1.
- SLSA Version 1.2 — current approved SLSA specification.
- NIST SP 800-218 Rev. 1 / SSDF Version 1.2 — draft/change-watch only until final publication.
- CISA and other implementation guidance are not treated as universal legal requirements.

## Languages

Controlled project editions are maintained in English (`en`), Latin American Spanish (`es-419`), and Brazilian Portuguese (`pt-BR`). Localizations are unofficial project translations.

## Release model

Publication requires controlled trilingual parity, reproducible DOCX/PDF generation, deterministic package/accessibility/render QA, immutable SHA-256 provenance, exact-byte durable staging, predecessor publication, and final catalog/release-registry reconciliation.
