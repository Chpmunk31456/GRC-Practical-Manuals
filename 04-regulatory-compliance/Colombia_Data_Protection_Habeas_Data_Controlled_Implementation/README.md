# Manual 37 — Colombia Data Protection / Habeas Data Controlled Implementation

This controlled implementation manual translates Colombia's general personal-data protection and habeas-data requirements into governance, privacy, security, evidence, assurance, vendor, incident, transfer/transmission, RNBD, and release-control practices.

The manual preserves source hierarchy: constitutional rights, Ley 1581 de 2012, applicable decrees consolidated in Decreto 1074 de 2015, binding SIC circulars/instructions, SIC guidance/enforcement materials, special data regimes, contracts, and organization-authored implementation choices are not treated as interchangeable.

Controlled editions are maintained in English, Latin American Spanish (`es-419`), and Brazilian Portuguese (`pt-BR`). Project translations are unofficial implementation translations and are not SIC-authorized legal translations.
