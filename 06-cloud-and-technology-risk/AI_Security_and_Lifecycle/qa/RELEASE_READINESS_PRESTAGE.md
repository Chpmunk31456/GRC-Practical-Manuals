# Manual 07 — Release Readiness Pre-stage

This control file keeps Manual 07 moving while earlier manuals complete their release sequence.

## Pre-staged non-human gates

- authoritative-source verification and source-state watch
- controlled English master completion
- AI lifecycle security/control evidence package
- threat-model and adversarial-testing review
- technical/security/editorial QA
- accessible graphics and text equivalents
- `es-419` localization draft
- `pt-BR` localization draft
- terminology/semantic review package
- DOCX/PDF generation and page QA
- release manifest, checksums and provenance
- repository/security release audit

## Human gates retained

- localized semantic approval where required
- final human release approval

## Fail-closed rule

Automated QA does not establish security effectiveness, certification, legal compliance, or an audit opinion. Material changes reopen affected review gates. Manual 07 must not bypass Manuals 03–06.
