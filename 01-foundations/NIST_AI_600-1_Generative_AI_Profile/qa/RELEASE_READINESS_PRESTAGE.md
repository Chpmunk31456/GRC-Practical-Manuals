# Manual 04 — Release Readiness Pre-stage

This control file keeps Manual 04 moving while Manual 03 completes its release sequence.

## Pre-staged non-human gates

- controlled English chapter master completion
- current NIST source-state verification and watch
- GAI applicability/tailoring register and risk-family evidence package
- content-provenance, pre-deployment testing and incident-disclosure workpapers
- technical/editorial/security/copyright QA
- accessible graphics and text equivalents
- `es-419` localization draft
- `pt-BR` localization draft
- terminology/semantic review package
- DOCX/PDF generation and page QA
- release manifest, checksums and provenance
- repository/security release audit

## Human gates retained

- localized semantic approval where required
- final human release approval

## Fail-closed rule

Automated QA does not certify a GAI system or establish legal compliance or trustworthy-AI achievement. Material changes reopen affected review gates. Manual 04 must not bypass Manual 03.
