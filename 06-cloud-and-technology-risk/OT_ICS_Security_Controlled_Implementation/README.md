# Manual 21 — OT / ICS Security Controlled Implementation

This directory contains the controlled-build source and eventual publication package for Manual 21, focused on operational technology (OT) and industrial control systems (ICS) security.

The controlling source architecture uses NIST SP 800-82 Rev. 3 as the primary public OT/ICS security baseline, the ISA/IEC 62443 series as a standards-family reference boundary, and CISA ICS/OT advisories and mitigations as operational risk inputs. Advisory material is not represented as a substitute for a control baseline, and copyrighted standards text is not reproduced.

Controlled publication languages are English, Spanish (es-419), and Portuguese (pt-BR). Project translations are unofficial unless separately documented otherwise. Publication is governed by the repository's canonical release authorization rule and fail-closed source, structure, localization, rendering, accessibility, integrity, provenance, workflow-security, and predecessor-order controls.
