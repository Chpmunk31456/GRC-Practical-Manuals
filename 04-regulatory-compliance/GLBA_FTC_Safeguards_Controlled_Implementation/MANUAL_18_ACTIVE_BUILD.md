# Manual 18 — GLBA / FTC Safeguards Rule Active Build

## Objective

Promote Manual 18 from preflight into active controlled build while Manual 17 is in QA. The manual must keep statutory, regulatory, agency-guidance, contractual, and implementation layers distinct.

## Controlled build scope

1. Applicability and covered financial-institution context
2. Customer-information and system boundary definition
3. Qualified Individual governance model
4. Risk assessment methodology and update triggers
5. Safeguard design and control ownership
6. Access control and least privilege
7. Authentication and MFA
8. Data inventory, classification, retention and disposal
9. Encryption and key-management implementation
10. Secure configuration and vulnerability management
11. Application security and change management
12. Monitoring, logging and detection
13. Penetration testing and vulnerability assessment
14. Service-provider oversight
15. Incident response and notification dependencies
16. Security awareness and workforce controls
17. Continuous monitoring and periodic testing
18. Board/senior-management reporting
19. Exceptions, compensating measures and remediation
20. Evidence retention and examination readiness
21. Integration with privacy obligations
22. Integration with cybersecurity frameworks
23. Small-entity/applicability nuances where authoritative text supports them
24. Remote work and cloud/shared-responsibility considerations
25. Vendor and fourth-party dependencies
26. Metrics and control-effectiveness reporting
27. Change triggers and reassessment
28. Regulatory update monitoring
29. Examination/request-response readiness
30. Remediation program governance
31. Localization and terminology controls
32. Release, provenance and lifecycle controls

## Evidence object

Map each implementation topic to applicability -> risk -> safeguard/control objective -> owner -> procedure -> frequency -> evidence -> test method -> exception/remediation -> reassessment trigger.

## Fail-closed boundaries

Do not conflate GLBA privacy provisions with the FTC Safeguards Rule, do not generalize FTC jurisdiction beyond authoritative applicability, and do not publish against stale regulatory text. Release-time authority verification, localization parity, rendered QA, provenance and durable-artifact controls remain mandatory.
