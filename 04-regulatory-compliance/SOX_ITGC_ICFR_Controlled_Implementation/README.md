# Manual 13 — SOX ITGC / ICFR Controlled Implementation

Status: CONTROLLED DEVELOPMENT / REVIEWER-READY BUILD IN PROGRESS

Manual 13 provides original, practical implementation guidance for technology controls relevant to internal control over financial reporting (ICFR). It is anchored to the Sarbanes-Oxley Act, SEC ICFR rules/guidance, and current PCAOB AS 2201 status while preserving the boundary between management responsibilities and external-auditor responsibilities.

## Scope

The manual covers ICFR scoping, financial-statement risk/assertion linkage, entity-level technology controls, logical access, segregation of duties, change management, development/acquisition, computer operations, interfaces, IPE/reports, spreadsheets/EUC, control design, operating effectiveness, evidence, population completeness, sampling readiness, service organizations, cloud/SaaS, financially relevant AI/automation, deficiencies, remediation, retesting, certification support, external-auditor interaction, monitoring, maturity paths, scenarios, and release controls.
