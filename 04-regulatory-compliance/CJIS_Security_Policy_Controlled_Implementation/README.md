# Manual 40 — CJIS Security Policy Controlled Implementation

Controlled implementation manual for the FBI Criminal Justice Information Services (CJIS) Security Policy, using Version 6.1 dated June 25, 2026 as the controlled federal baseline for this release.

## Source hierarchy
1. Current FBI CJIS Security Policy requirements and formally incorporated federal CJIS materials.
2. Applicable CJIS Advisory Policy Board / Compact Council requirements according to their actual legal or policy status.
3. State CJIS Systems Agency requirements and other jurisdiction-specific overlays, assessed separately from the federal baseline.
4. Contracts, interagency agreements, cloud/service-provider obligations, and agency-specific implementation requirements.
5. Organization-specific controls, procedures, evidence, and implementation choices.

## Publication boundary
The manual does not collapse state CSA overlays, contracts, implementation guidance, or organization practice into the FBI policy itself. Applicability, criminal justice versus noncriminal justice use, personnel/security screening, access, authentication, encryption, logging, incident handling, cloud/service-provider use, mobile/remote access, media protection, and audit evidence require documented context-specific analysis.

Controlled es-419 and pt-BR editions are project translations and are not official FBI translations. Publication remains sequential after Manual 39 and requires exact-candidate, provenance, accessibility/render, durable staging, predecessor, workflow-security, and final registry-reconciliation gates.
