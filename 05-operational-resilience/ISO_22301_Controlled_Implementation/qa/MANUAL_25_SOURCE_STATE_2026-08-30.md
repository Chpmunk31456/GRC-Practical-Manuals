# Manual 25 — ISO 22301 source-state decision

Verified release baseline as of 2026-08-30:

- ISO 22301:2019 remains the current published second edition.
- ISO 22301:2019/Amd 1:2024 is a published amendment and applies to the 2019 edition.
- ISO/CD 22301, Edition 3, is under development and is not a published replacement; it must be treated as change-watch only until formally published.
- ISO 22313:2020 is supporting guidance, not a substitute for the requirements standard.

Controlled boundaries:

- Do not reproduce copyrighted ISO normative text.
- Distinguish requirements, guidance, implementation examples, certification activity, and project-authored controls.
- Localized editions are unofficial project localizations and must not be described as ISO-authorized translations.
- Recheck ISO status immediately before release; adoption of a new published edition requires impact analysis and material-change revalidation.
- The 2024 climate-action amendment must be incorporated into the implementation/context boundary without overstating its scope.

Release state remains unchanged. This source decision supports controlled English drafting only.
