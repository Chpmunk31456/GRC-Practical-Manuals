# Manual 06 — Release Readiness Pre-stage

This control file keeps Manual 06 moving while earlier manuals complete their release sequence.

## Pre-staged non-human gates

- current-law source verification
- explicit separation of current HIPAA requirements from proposed Security Rule changes
- controlled English master completion
- legal/editorial/technical QA
- evidence and corrective-action workpapers
- accessible graphics and text equivalents
- `es-419` localization draft
- `pt-BR` localization draft
- terminology/semantic review package
- DOCX/PDF generation and page QA
- release manifest, checksums and provenance
- repository/security release audit

## Human gates retained

- qualified semantic/legal-context review where required
- final human release approval

## Fail-closed rule

Proposed-rule content remains readiness-only until a final rule changes the controlled legal baseline. Material changes reopen affected review gates. Manual 06 must not bypass Manuals 03–05.
