# Workbook Build Notes

The companion workbook contains:

- `Risk Register` — 41 controlled fields, 500 working rows, formulas for inherent/residual/target scores and levels, dropdown validation, date fields, and conditional formatting.
- `Treatment Plan` — treatment actions, milestones, resources, validation, evidence, and escalation.
- `Dashboard` — open-risk, critical/high residual, tolerance, overdue-review, and distribution summaries.
- `Lists` — controlled dropdown values.

The workbook was generated and verified using the project spreadsheet quality standard. Formula-error scanning returned no matches, and the dashboard was rendered for visual inspection before repository commit.
