# Manual 43 — ISO/IEC 27017 & 27018 Cloud Security / Cloud PII — Source / Architecture Gate

Status: active downstream prebuild. Publication remains sequential behind Manual 42.

## Current source boundary

- ISO/IEC 27017:2026, Edition 2, is published and is the current ISO cloud-security guidance baseline for this manual.
- ISO/IEC 27018:2025, Edition 3, is published and is the current public-cloud PII-processing guidance baseline.
- ISO/IEC 27002:2022 and ISO/IEC 27001:2022 are relationship/context sources; their copyrighted text is not reproduced.
- Provider/customer responsibilities, contracts, sector regulations, data-protection law, and provider-native guidance remain distinct from ISO guidance.
- Implementation guidance must not imply ISO certification, accreditation, conformity assessment, or legal compliance.
