# Manual 44 — NIST SSDF / SP 800-218 Controlled Implementation

Controlled implementation guidance for secure software development using NIST SP 800-218 SSDF v1.1 and SP 800-218A as the stable published baselines. Any SP 800-218 Rev.1 / SSDF v1.2 material remains change-watch unless reverified as final at release.

Controlled EN/es-419/pt-BR sources are under `controlled/`. Exact frozen DOCX/PDF publication artifacts will be retained under `publication/<locale>` after provenance verification. Publication requires source-version reverification, trilingual QA, immutable candidate provenance, document/PDF inspection, exact-byte staging, workflow-security validation, predecessor publication, and final registry reconciliation.
