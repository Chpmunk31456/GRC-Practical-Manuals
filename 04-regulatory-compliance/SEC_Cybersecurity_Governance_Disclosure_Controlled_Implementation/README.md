# Manual 33 — SEC Cybersecurity Governance and Disclosure Controlled Implementation

Manual 33 provides a controlled implementation method for the SEC's cybersecurity risk-management, strategy, governance, and incident-disclosure requirements for public-company reporting.

## Controlled editions

- `controlled/en/MANUAL_33_CONTROLLED_EN.md`
- `controlled/es-419/MANUAL_33_CONTROLLED_ES-419.md`
- `controlled/pt-BR/MANUAL_33_CONTROLLED_PT-BR.md`

Localized editions are unofficial project translations. They do not replace the English SEC rules/forms, current official SEC material, issuer counsel, or issuer-specific disclosure judgment.

## Controlled boundary

The manual keeps binding SEC rules/forms separate from Commission/staff guidance, proposals or non-effective material, enforcement/case-specific facts, and organisation implementation practice. It does not make issuer-specific materiality determinations or provide legal advice.

## Publication controls

Publication requires release-time source verification, 32-chapter trilingual parity, deterministic candidate generation, accessibility and rendered-page QA, immutable SHA-256 provenance, exact-byte staging, predecessor Manual 32 publication, and final catalog/release-registry reconciliation.
