# Multilingual GRC Production Status

## Objective

Expand the GRC Practical Manuals collection so each substantive manual is available in:

- English
- Spanish (Latin America)
- Brazilian Portuguese

Each language edition must include both:

- Editable DOCX
- Searchable PDF

## Required checks for every new edition

- [ ] Correct manual title, version, and language
- [ ] DOCX opens without repair warnings
- [ ] DOCX package ZIP/XML integrity passes
- [ ] PDF opens successfully
- [ ] PDF text is searchable and selectable
- [ ] No clipping, overlap, missing glyphs, or blank pages
- [ ] Headings, tables, lists, links, page breaks, headers, and footers reviewed
- [ ] Accessibility structure and reading order reviewed where supported
- [ ] No placeholder text or copied metadata
- [ ] Spanish terminology reviewed for Latin American usage
- [ ] Portuguese terminology reviewed for Brazilian usage
- [ ] Technical, legal, regulatory, and standards claims checked against current official sources

## Repository records to update

- [ ] Root README catalog and language availability
- [ ] Section READMEs
- [ ] Manual-folder READMEs
- [ ] CHANGELOG.md
- [ ] Version and status records
- [ ] Automated integrity audit
- [ ] Final publication report

## Publication rule

No edition may be marked complete until both DOCX and PDF files exist and the required structural, visual, accessibility, editorial, and language checks are documented.
