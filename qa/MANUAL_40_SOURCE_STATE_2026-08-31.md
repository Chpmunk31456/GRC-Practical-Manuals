# Manual 40 — CJIS Security Policy release-time source state

**State:** downstream prepublication source refresh.  
**Verified baseline:** FBI Criminal Justice Information Services Security Policy **Version 6.1, dated June 25, 2026**. Version 6.0 dated December 27, 2024 is superseded for the controlled release baseline.

## Controlled boundary
- CJIS Security Policy requirements, companion/resource-center materials, use cases, security addendum/agreements, state CSA implementation requirements, contracts, and organization-specific practices remain distinct.
- Do not treat resource-center examples or use cases as independently binding requirements.
- Applicability and responsibility depend on CJI access, agency role, system/service boundaries, outsourcing/contracting arrangements, and applicable CSA agreements.

## Release requirement
Reverify the FBI CJIS Security Policy Resource Center and exact current policy version at candidate freeze. Project translations are unofficial and must preserve FBI terminology without implying endorsement.
