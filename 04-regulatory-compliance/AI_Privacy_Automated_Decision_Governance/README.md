# Manual 28 — AI Privacy & Automated Decision Governance

Controlled implementation manual for governing privacy, profiling, automated decision systems, AI-assisted decisions, and consequential decision workflows without collapsing voluntary guidance and jurisdiction-specific legal requirements into a single rule set.

## Controlled source package

- `controlled/en/MANUAL_28_CONTROLLED_EN.md` — controlling English project source.
- `controlled/es-419/MANUAL_28_CONTROLLED_ES-419.md` — unofficial Latin American Spanish project translation.
- `controlled/pt-BR/MANUAL_28_CONTROLLED_PT-BR.md` — unofficial Brazilian Portuguese project translation.

## Source boundary

The release baseline uses NIST Privacy Framework 1.0 and NIST AI RMF 1.0 as published voluntary guidance while tracking their announced revisions separately. Jurisdiction-specific privacy, profiling, automated-decision, AI, employment, credit, insurance, biometric, children’s-data, consumer-protection, and sector obligations must be assessed independently for each use case.

## Publication controls

Publication is sequential after Manual 27. Candidate DOCX/PDF artifacts must be reproducibly generated from the controlled sources, hash-bound, deterministically checked, render-reviewed, durably staged without regeneration, and reconciled into the release catalog only after applicable objective gates are green.
