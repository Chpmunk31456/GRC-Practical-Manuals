# Manual 23 — DORA Controlled Implementation

This directory contains the controlled-build source and eventual publication package for Manual 23.

Primary statutory baseline: Regulation (EU) 2022/2554 (Digital Operational Resilience Act), with applicable delegated and implementing acts, current ESA/EU supervisory materials, and organization-specific implementation procedures maintained as distinct source layers. DORA does not replace GDPR, NIS2, sectoral prudential law, or applicable national law.

Controlled publication languages are English, Spanish (es-419), and Portuguese (pt-BR). Project translations are unofficial unless separately documented otherwise. Publication is governed by the repository canonical release authorization rule and fail-closed source, applicability, localization, rendering, accessibility, integrity, provenance, workflow-security, and predecessor-order controls.
