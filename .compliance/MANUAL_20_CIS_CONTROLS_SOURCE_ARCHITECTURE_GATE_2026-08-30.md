# Manual 20 — CIS Controls v8.1 Controlled Source and Architecture Gate

**Series order:** 20  
**State:** source verification + controlled architecture preparation; not publication authorization

## Current authoritative source state

Official Center for Internet Security materials were reverified on 2026-08-30. CIS identifies **CIS Critical Security Controls v8.1** as the current/latest Controls release. CIS describes v8.1 as an iterative update to v8 with revised asset classes and Safeguard descriptions, updated alignment to evolving standards, and NIST CSF 2.0 Govern-function alignment. The official v8.1 page also exposes the Controls package, change log and Implementation Groups. A Spanish v8.1 guide translation is available from CIS; project es-419 and pt-BR editions must nevertheless remain controlled project localizations unless the exact official translation/license scope is deliberately adopted and evidenced.

Authoritative references for release-time reverification:
- `https://www.cisecurity.org/controls/v8-1`
- `https://www.cisecurity.org/controls`
- `https://www.cisecurity.org/controls/cis-controls-list`

Do not reproduce protected CIS text beyond permitted quotation/use. Keep CIS Controls, CIS Safeguards, Implementation Groups, CIS Benchmarks, NIST mappings, and organization-specific procedures conceptually distinct.
