# Manual 22 — Cloud Security Controlled Implementation

This directory contains the controlled-build source and eventual publication package for Manual 22.

The controlling source architecture uses Cloud Security Alliance CCM v4.1 as the current primary cloud-controls reference state, with transition awareness for v4.0.x and carefully separated provider-native implementation guidance. Crosswalks and cloud-provider certifications are not treated as automatic control or legal equivalence, and implementation of this manual does not imply CSA STAR registration, attestation, or certification.

Controlled publication languages are English, Spanish (es-419), and Portuguese (pt-BR). Project translations are unofficial unless separately documented otherwise. Publication is governed by the repository's canonical release authorization rule and fail-closed source, structure, localization, rendering, accessibility, integrity, provenance, workflow-security, and predecessor-order controls.
