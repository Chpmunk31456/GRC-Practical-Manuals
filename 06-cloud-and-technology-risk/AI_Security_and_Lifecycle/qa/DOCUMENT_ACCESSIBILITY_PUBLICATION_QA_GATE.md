# Manual 07 — Document, Accessibility & Publication QA Gate

Status: PRE-STAGED / FAIL-CLOSED

Required before publication:
- accessible DOCX and PDF candidates for every approved language;
- page-level visual QA for threat models, lifecycle workflows, security tables, incident/rollback procedures and figures;
- alt text/accessibility verification for all instructional graphics;
- metadata, language tags, reading order, links and bookmarks verified;
- release manifest and checksums tied to the exact reviewed commit;
- security caveats and authorization boundaries preserved;
- no publication claim may imply that repository QA proves a system secure.

Any substantive source, translation or security-boundary change invalidates affected artifacts and requires regeneration/re-review. Final Human Release Approval remains mandatory.
