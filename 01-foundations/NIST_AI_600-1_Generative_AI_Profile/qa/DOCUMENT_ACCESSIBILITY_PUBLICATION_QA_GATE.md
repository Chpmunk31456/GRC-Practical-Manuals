# Manual 04 — Document, Accessibility & Publication QA Gate

Status: PRE-STAGED / FAIL-CLOSED

## Required release artifacts

- Accessible DOCX candidate for each approved publication language.
- Accessible PDF candidate for each approved publication language.
- Page-level visual review covering headings, tables, lists, links, figures, captions, page breaks and clipping.
- Alt text / accessible explanation verification for every instructional graphic.
- Artifact checksums and release manifest tied to the reviewed commit.
- Document metadata, language tags and reading order verified.
- No unsupported certification, legal-compliance or trustworthy-AI claims.

## Release rule

Automated conversion success is insufficient. Any substantive source or translation change after document QA invalidates affected artifacts and requires regeneration and re-review. Final Human Release Approval remains mandatory.
