# Roadmap Release Order

The production sequence is controlled as follows:

1. Manual 07 — front-of-line release/QC
2. Manual 08 — downstream full-build/pre-release lane
3. Manual 09 — downstream controlled-build lane
4. Manual 10 — downstream pre-stage lane
5. Manuals 11–45 — research/architecture/training-content pre-stage only until upstream release dependencies permit promotion

No roadmap entry may be promoted solely because planning or draft content exists. Promotion requires the same fail-closed release operating procedure used by the current series.
