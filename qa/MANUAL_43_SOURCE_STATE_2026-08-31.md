# Manual 43 — ISO/IEC 27017 & 27018 release-time source state

**State:** downstream prepublication source refresh.  
**Verified baseline:** **ISO/IEC 27017:2026 Edition 2** is published and supersedes ISO/IEC 27017:2015. **ISO/IEC 27018:2025 Edition 3** is published and supersedes ISO/IEC 27018:2019.

## Controlled boundary
- ISO/IEC 27017:2026 cloud-security guidance and ISO/IEC 27018:2025 public-cloud PII-processor guidance remain separate standards with distinct scopes.
- ISO/IEC 27001/27002, ISO/IEC 27701, privacy law, cloud contracts, shared-responsibility allocations, certifications/assessments, and organization-specific practices remain separate source layers.
- Project-authored implementation guidance must not reproduce protected normative standard text or imply ISO authorization.

## Release requirement
Use only project-authored summaries, mappings, procedures, evidence objects, and implementation guidance. Reverify ISO catalog edition/status at candidate freeze. Controlled translations are unofficial.
