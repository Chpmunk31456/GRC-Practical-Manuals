# Manual 25 — ISO 22301 Business Continuity Management Controlled Implementation

This directory contains the controlled-build source and publication package for Manual 25.

Primary published requirements baseline: ISO 22301:2019 together with ISO 22301:2019/Amd 1:2024. ISO 22313:2020 is supporting guidance rather than a substitute for the requirements standard. ISO/CD 22301 Edition 3 and ISO/AWI 22313 Edition 3 are under-development change-watch material only until formally published and must not be treated as controlling requirements.

Protected ISO normative text is not reproduced. Requirements, guidance, implementation examples, certification activity, internal policy, contractual obligations, regulatory overlays, and project-authored controls remain distinct source layers. The 2024 climate-action amendment is incorporated into context and interested-party analysis without overstating its scope.

Controlled publication languages are English, Spanish (es-419), and Portuguese (pt-BR). Project translations are unofficial unless separately documented otherwise. Publication is governed by the repository canonical release authorization rule and fail-closed source, applicability, localization, rendering, accessibility, integrity, provenance, workflow-security, substantive-review, and predecessor-order controls.
