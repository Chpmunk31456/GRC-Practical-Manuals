# Manual 34 — ISO/IEC 27701:2025 Privacy Information Management Controlled Implementation

This directory contains the controlled implementation source and publication artifacts for Manual 34.

## Controlled baseline

The release baseline is ISO/IEC 27701:2025, Edition 2, published by ISO in October 2025. ISO/IEC 27701:2019 is withdrawn and is not used as the controlling edition.

This project does not reproduce ISO copyrighted normative text. It provides original implementation guidance, evidence architecture, operating-model patterns, and controlled references to publicly available bibliographic facts and concepts.

## Language editions

Controlled source editions are maintained in:

- `controlled/en/` — controlled English master
- `controlled/es-419/` — unofficial project Spanish (Latin America) localization
- `controlled/pt-BR/` — unofficial project Brazilian Portuguese localization

Project translations are not ISO-authorized translations.

## Publication controls

Publication requires the predecessor Manual 33 to be published, exact trilingual source parity, reproducible six-binary DOCX/PDF generation, immutable SHA-256 provenance, rendered/accessibility QA, durable exact-byte staging, workflow-security controls, and final catalog/work-product release-registry reconciliation.
