# Manual 43 — ISO/IEC 27017 & 27018 Cloud Security and Privacy Controlled Implementation

Project-authored implementation guidance for cloud security and public-cloud privacy using ISO/IEC 27017:2026 Edition 2 and ISO/IEC 27018:2025 Edition 3 as controlled reference baselines, subject to release-time reverification.

This repository does not reproduce protected ISO control text and these project editions are not authorized ISO translations. Controlled EN/es-419/pt-BR sources are under `controlled/`; exact frozen DOCX/PDF publication artifacts will be retained under `publication/<locale>` after provenance verification.
