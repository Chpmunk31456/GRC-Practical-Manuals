## Notice / Aviso / Aviso

Cloud responsibilities vary by service model, provider, contract, data classification, architecture, industry, and jurisdiction. Verify current provider documentation and applicable requirements.

Las responsabilidades en la nube varían según el modelo de servicio, proveedor, contrato, clasificación de datos, arquitectura, industria y jurisdicción. Verifique la documentación vigente del proveedor y los requisitos aplicables.

As responsabilidades de nuvem variam conforme o modelo de serviço, provedor, contrato, classificação de dados, arquitetura, setor e jurisdição. Verifique a documentação atual do provedor e os requisitos aplicáveis.
