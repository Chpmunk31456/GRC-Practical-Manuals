# Manual 36 — Brazil LGPD Controlled Implementation

This controlled implementation manual translates the current Brazilian LGPD and applicable ANPD regulatory requirements into governance, privacy-engineering, security, evidence, assurance, and release-control practices.

The manual maintains strict source hierarchy. LGPD statutory requirements and binding ANPD regulations are not conflated with ANPD guidance, FAQs or enforcement material; adjacent sector or digital-law obligations; contractual commitments; or organization-authored implementation choices.

Controlled editions are maintained in English, Latin American Spanish (`es-419`), and Brazilian Portuguese (`pt-BR`). Project localizations are unofficial implementation translations and must not be represented as official statutory or ANPD wording.

Publication remains fail-closed until source reverification, trilingual structure/parity QA, reproducible six-binary DOCX/PDF candidate generation, accessibility/render inspection, SHA-256 provenance, exact-byte staging, predecessor Manual 35 publication, and final catalog/release-registry reconciliation all pass.
