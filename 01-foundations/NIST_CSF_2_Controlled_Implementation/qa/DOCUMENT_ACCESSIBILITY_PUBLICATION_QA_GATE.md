# Manual 09 — Document, Accessibility & Publication QA Gate

Status: PRE-STAGED / FAIL-CLOSED

Required before publication:
- accessible DOCX and PDF candidates for English, `es-419`, and `pt-BR`;
- page-level visual QA for Profiles, Tiers, six-Function workflows, mappings, tables, and figures;
- alt text/accessibility verification for instructional graphics;
- metadata, language tags, reading order, links, bookmarks, tables, and headings verified;
- release manifest and SHA-256 checksums tied to the exact reviewed commit;
- Informative References and implementation mappings presented as supporting relationships, not proof of compliance or control effectiveness;
- repository/workflow security review complete;
- no publication claim may imply that repository QA proves cybersecurity effectiveness.

Any substantive source, translation, mapping, or architecture change invalidates affected artifacts and requires regeneration and re-review. Final Human Release Approval remains mandatory.
