# Manual 51 — Agentic AI Governance, Security & Human Accountability

**Publication state:** final exact-candidate publication transaction  
**Currentness baseline:** 1 September 2026

Manual 51 provides a practical governance, security, identity, authorization and human-accountability model for AI agents that can plan, invoke tools, access enterprise data, use memory, delegate to other agents and take consequential actions.

## Core architecture

The controlled publication source implements AG-01 through AG-20 covering agent identity, credential control, least privilege, autonomy bounding, meaningful human checkpoints, tool/MCP/API trust boundaries, data and memory, prompt/instruction integrity, action provenance, multi-agent delegation, third-party governance, monitoring, containment, incident response, change/revalidation, adversarial testing, automation-bias controls, user transparency, risk acceptance and continuous assurance.

## Source-status discipline

IMDA agentic-AI material is treated as government governance guidance. NIST AI RMF and AI 600-1 are treated as voluntary risk-management guidance. NIST's 2026 agent identity/authorization concept material is not represented as a final mandatory standard. OWASP agentic security material is treated as community security guidance. The manual does not claim legal or certification equivalence among these source families.

## Human-accountability rule

A person nominally present in a workflow does not by itself constitute effective human oversight. A meaningful checkpoint requires an identifiable and competent person with sufficient context, real authority to reject, and a technical mechanism that prevents the consequential action when approval is denied.
